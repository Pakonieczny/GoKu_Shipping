# Avatar experience51: verified release package

The avatar now retains the current recipient, occasion and shopper's own reason for a gift across long conversations, heavy browsing, navigation, same-tab reload and voice restarts. The current product and its actual choices stay separate from that gift context, so an earlier charm or recipient cannot take over the current piece.

## Resulting behavior

| Area | Implemented and checked |
| --- | --- |
| Meaning | Connect the exact current charm to what the shopper explicitly shared. Fresh approved interpretations retain their source links; personal connections use qualified wording rather than invented cultural or universal claims. A named different or unknown charm cannot borrow the current charm's meaning. |
| Gift continuity | Current gift corrections win over older history. Explicit new gifts, self purchases, account changes and fresh starts reset the appropriate topic. Late account hydration and stale replies cannot revive an earlier gift. |
| Suggestions | Hesitant language can offer similar designs. Enthusiasm can offer optional complementary pieces of the same or closely related charm across categories. At most two optional pieces are offered, sold separately, using fresh checked variants that satisfy availability, metal, price and currency constraints. Suggestions never select options or add pieces automatically. |
| Website control | Existing cart, exact line menus, option selections, quantity, highlights, scrolling, gallery, navigation and review cancellation remain covered. Real choices update the ongoing voice context; pointer gaze and touch previews stay local. |
| Long discussions | Bounded conversation, memory and suggestion journals preserve the active gift without growing indefinitely or restarting voice on every navigation. Retired provider responses and late meaning reads cannot act on a newer page or gift. |
| Privacy | Contact numbers, credentials, private field wording and instruction-like text cannot enter personal gift context. Both widget and voice withhold gift context until the shared privacy filter is ready, then resume only normalized saved context. |
