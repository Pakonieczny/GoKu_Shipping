# Experience 51 independent acceptance

This audit belongs to `tests/growth/avatar-experience51-adversarial.test.cjs`. It tests the production shopping guide and the real widget, sandbox storefront, bridge, native voice client, finalized ASR callback and provider action guard. The catalogue, knowledge response, source text, network, microphone, media transport and provider events are synthetic. The museum URL is an attribution fixture; this audit does not claim that its real page supports the invented test interpretation.

The independent catalogue contains 120 products. The literal expected cohorts are a butterfly necklace alternative and a butterfly earring companion, with otter pieces for a corrected current page. Owl earrings and a circle listing containing a butterfly cross-sell sentence must not qualify as matching butterfly pieces. The guide also checks one exact variant against stock, material, currency and budget together.

## Findings and evidence

The first independent native quote case reproduced an unintended product-to-catalogue navigation for `The note says "show me matching earrings".` The guide initially reported the stripped quoted intent as `denied:false`; a suppressed guide suggestion still allowed the legacy search fallback. The corrected classifier and widget non-request guard preserve the actual page and prevent the search/presentation fallback. The exact page, control and recommendation assertions remain.

The actual meaning UI test reproduced a separate integration loss: the fresh `/api/growth/knowledge` response contained an exact-product interpretation and checked source, but the widget removed the source's `checkedAt` before passing it to the guide. The guide correctly rejected the incomplete attribution, leaving `personal-connection` instead of the expected `reviewed-interpretation`. The widget now retains a validated positive source timestamp, while the guide enforces attribution freshness. The complete source link and qualification assertions pass unchanged.

Two fixture expectation corrections do not change production behavior: the established public normalization canonicalizes `my sister` to `sister`, and the actual sandbox note field is `[name="note"]`. Assertions still compare all four personal fields and the full literal private note value.

The final read-only review reproduced two account timing gaps through the real widget's memory callbacks. First, `A different gift now.` left three empty gift fields and a current topic marker, but an older account hydration filled mother/anniversary/patience and erased the marker. Second, resolving the same pending account after an ordinary quantity question lost its prior sister/graduation/keep-going context despite retaining those stored preferences. The widget now respects explicit current topics, restores held same-owner context when newer turns were ordinary commands, and keeps newer explicit corrections/resets with their exact current topic marker. Absent gift fields are also removed from merged preferences. These assertions pass alongside different-owner and Start fresh isolation.

Server review identified a conflicting named-piece meaning target. The widget now checks the requested identity before reading the current interpretation; exact known-different and unknown-name questions both clarify rather than borrowing the current piece's story. The two native regressions pass without a knowledge fetch or shopping action.

Historical intermediate evidence is retained outside the repository: `../avatar51-adversarial-second.tap` completed 21/24, with these two fixture corrections and the attribution integration failure; `../avatar51-fixture-negative-guard.tap` completed the four selected corrected/cancellation/negative cases 4/4. The focused exact meaning UI rerun `../avatar51-meaning-ui-fixed.tap` passed 1/1.

It completed **32/32**, **0 fail, cancelled, skipped or todo**, in **8,857.591792 ms**. This final total comprises 15 guide/context cases and 17 actual widget/native cases; the 100-turn loop is one of those cases. No ordinary typed/chat network fallback or physical microphone is substituted for the native ASR callback. The one explicitly permitted typed case invokes the real shopper handler and retains the fixture's ordinary-chat network prohibition. The account cases capture the production widget callbacks through a synthetic memory client; they certify widget adoption and isolation, not live account service behavior.

These changes were checked without changing the assertions in this file's 32 cases or the existing adversarial suites. The final privacy review found that a phone number in a gift reason could pass the shared filter, and that the browser's pre-helper context fallback preserved phone, credential and private-note strings. A direct production browser-script evaluation reproduced the latter through both `publicContext` and `publicMemory`; a real widget fixture reproduced the saved-context fallback as well. The shared normalizer now rejects formatted phone numbers. Both voice and widget withhold personal-context projections until that shared filter is available. The widget preserves bounded remembered data only in memory during startup, then normalizes it when the real helper arrives so a legitimate recipient, occasion and reason can resume.

Two explicit startup regressions were added without changing the previous 32 case assertions.
