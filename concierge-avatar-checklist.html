BRITES JEWELRY · VISUAL ACCEPTANCE

Check the live 3-D guide.

Use a browser with WebGL 2 support. This test page makes no product, cart or store changes and never changes browser graphics settings or fingerprinting.

Open the visual studio

  1. Confirm renderer identity. Click Run 15-second sample. A GPU-capable result must say mode: "webgl", list an available WebGL context and show the browser-reported vendor, renderer and version. Missing vendor details are recorded as unavailable, never guessed.
  2. Confirm capability, not appearance. Check shadowMap, textures and pixelRatio. Shadow capability requires a configured casting light, receiving stage, depth buffer and enough observed texture capacity. This still does not prove that shadows look correct.
  3. Sample frames. Check frameSampling and longTasks for the measured window, median/p95 values and first-frame evidence. A positive sample is evidence only for that browser and moment; it is not a performance guarantee.
  4. Try every expression. Use Run all states and individually select idle, listening, thinking, speaking, success and error. Twin light ribbons, brows, smile, head, fins and light should respond. These studio controls do not turn on a microphone or speak automatically.
  5. Check pause, hide, reduced motion and context state. Pause while the guide stays visible, then resume; separately hide and show it. Check motion for visibility, pause, animation and reduced-motion state, and contextLoss for any observed loss. The harness reports state only and never forces a context loss.
  6. Visually inspect the finish in a WebGL-capable browser. Look for smooth ivory ceramic and champagne metal, the twin luminous eye ribbons, satin visor, stable reflections and a moving contact shadow on the stage. Also open the shopper demo and use Guide me to check that a real shadow remains visible beside the shopping controls. Check for seams, flicker, clipping, z-fighting or broken surfaces.

If WebGL is unavailable: the animated 2-D fallback must remain visible and gpu, shadows and fps must read unverified. Do not treat configured lights, texture declarations or target FPS as observed GPU output. Visual quality, real-time shadows and frame rate require a browser that actually renders the 3-D scene.
