BRITES JEWELRY · VISUAL ACCEPTANCE

Check the live 3-D guide.

Use a browser with WebGL 2 support. This test page makes no product, cart or store changes and never changes browser graphics settings or fingerprinting.

Open the visual studio

  1. Confirm renderer identity. Click Inspect renderer. A GPU-capable result must say mode: "webgl", list an available WebGL context and show the browser-reported vendor, renderer and version. Missing vendor details are recorded as unavailable, never guessed.
  2. Confirm capability, not appearance. Check shadowMap, textures and pixelRatio. Shadow capability requires a configured casting light, receiving stage, depth buffer and enough observed texture capacity. This still does not prove that shadows look correct.
  3. Sample frames. Check frameSampling for the measured window, frame delta and effective FPS. A positive sample is evidence only for that browser and moment; it is not a performance guarantee.
  4. Try every expression. Select idle, listening, thinking, speaking, success and error. Eyes, lids, brows, mouth and posture should respond. These studio controls do not turn on a microphone or speak automatically.
  5. Check pause, reduced motion and context state. Hide the guide and inspect again. Check motion for visibility, animation and reduced-motion state, and contextLoss for any observed loss. The harness reports state only and never forces a context loss.
  6. Visually inspect the finish in a WebGL-capable browser. Look for smooth ivory and champagne surfaces, aquamarine irises, reflective eye lenses, a sapphire pendant, and a moving shadow on the stage. Check for flicker, missing parts or broken surfaces.

If WebGL is unavailable: the static illustration must remain visible and gpu, shadows and fps must read unverified. Do not treat configured lights, texture declarations or target FPS as observed GPU output. Visual quality, real-time shadows and frame rate require a browser that actually renders the 3-D scene.
